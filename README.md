# Location-Based Attendance App

A web-based attendance application that uses GPS location verification to manage employee attendance. The application checks users' current locations against a predefined office radius to determine whether they are eligible to check in or check out.

## Key Features

- **Location-Based Attendance** – Uses GPS to detect the user's location during attendance.
- **Geofencing** – Validates whether the user is within the designated office radius before allowing attendance submission.
- **Check-In** – Allows users to record their arrival time and location.
- **Check-Out** – Allows users to record their departure.
- **Attendance Status** – Displays attendance results based on location verification.
